# Calculadora de Notas

Projeto simples desenvolvido com HTML, CSS e JavaScript para calcular a média de três notas e informar se o aluno foi aprovado ou reprovado.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Digite três notas entre 0 e 10.
4. Clique em **Calcular média**.

## Regra de aprovação
O aluno é aprovado quando a média é igual ou maior que 7.

## Autoria
Projeto acadêmico/pessoal desenvolvido para praticar conceitos básicos de desenvolvimento web.
